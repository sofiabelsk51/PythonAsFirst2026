## 1. Что такое цикл?

Цикл — это повторение одних и тех же действий несколько раз. В Python два основных вида:

- for — когда заранее известно, сколько раз повторять (или есть готовая последовательность);
- while — когда повторяем, пока условие истинно, а число итераций заранее неизвестно.

### Цикл for и range

    for i in range(1, 5):
        print(i)          # 1 2 3 4 — правая граница не включается

range(start, stop, step):
- range(5) → 0, 1, 2, 3, 4;
- range(1, 10, 2) → 1, 3, 5, 7, 9;
- range(10, 0, -1) → 10, 9, ..., 1.

### Цикл while

    x = 1
    while x < 100:
        x = x * 2

Повторяется, пока условие True. Важно, чтобы внутри что-то менялось, иначе цикл станет бесконечным.

### break и continue

- break — немедленно выйти из цикла;
- continue — перейти к следующей итерации, пропустив остаток тела.

    for m in range(2, n):
        if n % m != 0:
            continue
        # сюда попадаем только для делителей

### Накопление результата

Типичный шаблон: завести переменную-аккумулятор до цикла и обновлять её внутри.

    result = 1
    for i in range(1, n):
        result = result * i

## 2. Разбор примеров из файла

### Пример 1. factorial(n)

    def factorial(n):
        result = 1.0
        for i in range(1, n):
            result = result * i
        return result

Идея: накапливаем произведение. Обрати внимание: range(1, n) не включает n — для факториала это даёт (n-1)!. Проверь на бумаге, что именно должна возвращать функция по задумке автора, и при необходимости поправь границу.

### Пример 2. isPrime(n)

    def isPrime(n):
        if n < 2:
            return False
        if n == 2:
            return True
        if n % 2 == 0:
            return False
        for m in range(3, int(math.sqrt(n)) + 1, 2):
            if n % m == 0:
                return False
        return True

Идея: проверяем делители только до корня из n и только нечётные. В файле есть опечатки (false/true строчными, пропущен return после проверки чётности, sqrt без math., граница range без +1). Вот исправленная версия — сверь со своей.

Почему до корня? Если у числа есть делитель больше корня, то парный ему делитель меньше корня, и мы его уже проверили.

### Пример 3. isPerfect(n)

    def isPerfect(n):
        total = 1
        for m in range(2, n // 2 + 1):
            if n % m > 0:
                continue
            total += m
            if total > n:
                break
        return total == n

Идея: совершенное число равно сумме своих делителей (кроме самого себя). continue пропускает неделители, break досрочно выходит, если сумма уже превысила n. В файле range(2, n/2) даёт вещественную границу — нужно n // 2 + 1.

### Пример 4. digitCountInNumber(n, m)

В файле это рекурсивная функция с ошибками (m == m всегда истинно, деление / вместо //). Мы рекурсию ещё не проходили — эту задачу удобнее решить циклом:

    def digitCountInNumber(n, m):
        count = 0
        while n > 0:
            if n % 10 == m:
                count += 1
            n = n // 10
        return count

Идея: на каждой итерации n % 10 даёт последнюю цифру, n // 10 отбрасывает её. Пока n > 0 — продолжаем.

## 3. Домашнее задание: идеи и подсказки

Готового кода нет — пиши сам. В задачах, где запрещены строки, используй % и //.

### Задача 1. digitNumber(n) — 2 балла

Что сделать: количество цифр в числе. Строки запрещены.

Подсказка: цикл while n > 0, внутри n = n // 10 и счётчик += 1. Отдельно подумай про n = 0 — у него одна цифра.

Проверь себя: digitNumber(1) → 1; digitNumber(456) → 3; digitNumber(65536) → 5; digitNumber(0) → 1.

### Задача 2. fib(n) — 2 балла

Что сделать: n-е число Фибоначчи: fib(1)=1, fib(2)=1, каждое следующее — сумма двух предыдущих.

Подсказка: две переменные a = 1, b = 1; в цикле от 3 до n обновляй: a, b = b, a + b. После цикла верни b.

Проверь себя: fib(1) → 1; fib(2) → 1; fib(6) → 8; fib(10) → 55.

### Задача 3. minDivisor(n) — 2 балла

Что сделать: минимальный делитель числа n > 1, превышающий 1.

Подсказка: перебирай d от 2 вверх, пока d * d <= n; первый найденный делитель — ответ. Если не нашли — само n (оно простое).

Проверь себя: minDivisor(15) → 3; minDivisor(7) → 7; minDivisor(9) → 3; minDivisor(2) → 2.

### Задача 4. maxDivisor(n) — 2 балла

Что сделать: максимальный делитель числа n > 1, меньший n.

Подсказка: самый большой собственный делитель — это n // minDivisor(n). Можно переиспользовать предыдущую функцию. Альтернатива — перебор d от n // 2 вниз, но это медленнее.

Проверь себя: maxDivisor(15) → 5; maxDivisor(7) → 1; maxDivisor(9) → 3; maxDivisor(10) → 5.

### Задача 5. collatzSteps(x) — 2 балла

Что сделать: сколько шагов нужно, чтобы последовательность Коллатца дошла до 1. Правило: чётное → x // 2, нечётное → 3 * x + 1.

Подсказка: цикл while x != 1, внутри ветвление по чётности и счётчик шагов. Осторожно с //, а не /.

Проверь себя: collatzSteps(1) → 0; collatzSteps(2) → 1; collatzSteps(15) → 17.

### Задача 6. lcm(m, n) — 3 балла

Что сделать: наименьшее общее кратное.

Подсказка: НОК = m * n // НОД(m, n). НОД ищи алгоритмом Евклида в цикле: while b != 0: a, b = b, a % b.

Проверь себя: lcm(4, 6) → 12; lcm(3, 5) → 15; lcm(6, 8) → 24; lcm(1, 7) → 7.

### Задача 7. isCoPrime(m, n) — 3 балла

Что сделать: взаимно простые ли числа (НОД = 1).

Подсказка: тот же алгоритм Евклида, в конце сравни a == 1.

Проверь себя: isCoPrime(25, 49) → True; isCoPrime(6, 8) → False; isCoPrime(1, 5) → True; isCoPrime(14, 21) → False.

### Задача 8. squareBetweenExists(m, n) — 3 балла

Что сделать: есть ли хотя бы один точный квадрат в [m, n].

Подсказка: найди k = int(math.sqrt(m)) и проверь несколько соседних k (например, от k до k + 1): попадает ли k*k в [m, n]. Важно аккуратно с границами и округлением.

Проверь себя: squareBetweenExists(21, 28) → True (25); squareBetweenExists(51, 61) → False; squareBetweenExists(1, 1) → True; squareBetweenExists(2, 3) → False.

### Задача 9. revert(n) — 3 балла

Что сделать: перевернуть цифры числа. Строки запрещены.

Подсказка: аккумулятор result = 0; в цикле result = result * 10 + n % 10, затем n = n // 10.

Проверь себя: revert(13478) → 87431; revert(120) → 21; revert(5) → 5.

### Задача 10. isPalindrome(n) — 3 балла

Что сделать: является ли число палиндромом. Строки запрещены.

Подсказка: самый короткий путь — сравнить n с revert(n) из предыдущей задачи.

Проверь себя: isPalindrome(15751) → True; isPalindrome(3653) → False; isPalindrome(7) → True.

### Задача 11. hasDifferentDigits(n) — 3 балла

Что сделать: есть ли в числе хотя бы две различающиеся цифры. Строки запрещены.

Подсказка: можно для каждой цифры d = n % 10 пройти по оставшейся части числа n // 10 и проверить, встречается ли d ещё раз. Если встретилась — True, иначе продолжаем. Не забудь, что 0 — одна цифра, у него различающихся нет.

Проверь себя: hasDifferentDigits(54) → True; hasDifferentDigits(323) → True; hasDifferentDigits(111) → False; hasDifferentDigits(0) → False.

### Задача 12. sin(x, eps) — 4 балла

Что сделать: вычислить sin(x) рядом Тейлора с точностью eps. math.sin запрещён.

Подсказка:
- ряд: x - x³/3! + x⁵/5! - x⁷/7! + ...;
- заведи term = x, result = x, k = 1;
- на каждой итерации домножай term на -x*x / ((2k) * (2k+1)), прибавляй к result, увеличивай k;
- условие остановки: abs(term) < eps;
- про «быструю сходимость при больших x»: можно привести x к диапазону [-π, π], вычитая 2π, — тогда ряд сходится быстрее.

Проверь себя: сравни с math.sin(x) при разных x и eps (например, x = 0.5, eps = 1e-10 — должны совпасть до 9–10 знаков).

### Задача 13. cos(x, eps) — 4 балла

Что сделать: аналогично, но cos(x) = 1 - x²/2! + x⁴/4! - ....

Подсказка: term = 1, result = 1, k = 1; домножай term на -x*x / ((2k-1) * (2k)); остановка по abs(term) < eps.

Проверь себя: сравни с math.cos(x).

### Задача 14. squareSequenceDigit(n) — 4 балла

Что сделать: n-я цифра последовательности квадратов 14916253649.... Строки запрещены.

Подсказка: иди по k = 1, 2, 3, ..., для каждого считай k*k и количество его цифр; вычитай из n, пока не поймёшь, в какое число попала нужная цифра. Затем извлеки нужную цифру через // и %.

Проверь себя: squareSequenceDigit(2) → 4; squareSequenceDigit(7) → 5; squareSequenceDigit(12) → 6.

### Задача 15. fibSequenceDigit(n) — 5 баллов

Что сделать: n-я цифра последовательности чисел Фибоначчи 1123581321.... Строки запрещены.

Подсказка: та же идея, что и в задаче 14, только вместо квадратов — числа Фибоначчи (используй fib или две переменные a, b). Считай длину каждого числа через digitNumber из задачи 1.

Проверь себя: fibSequenceDigit(2) → 1; fibSequenceDigit(9) → 2; fibSequenceDigit(14) → 5.

## 4. Частые ошибки — проверь себя

1. range(1, n) вместо range(1, n + 1) — правая граница не включается.
2. / вместо // при работе с цифрами — получаются вещественные числа.
3. Бесконечный while — забыл изменить переменную условия внутри цикла.
4. range с вещественной границей (n / 2) — нужно целое (n // 2).
5. break и continue перепутаны — break выходит, continue пропускает итерацию.
6. False/True строчными буквами — в Python это False и True с большой.
7. sqrt без math. — не забывай про модуль.
8. return внутри цикла — выходит из функции целиком, а не из цикла; иногда это ошибка, иногда — задумка.
